Customizable Brightness 1.1.0. Press B to cycle brightness (0% to 1000%+ by default).

- New: Minecraft 26.3 support.
- Fixed: brightness could come back wrong after a restart (for example after using the vanilla Brightness slider and then pressing B). The mod's config is now the single source of truth, and both B and the slider persist correctly.
- Fixed: "Error saving option Brightness ... outside of range" was logged on every options save above 100%.
- Fixed: the keybind category showed as a raw translation key in Controls.
- New: a tutorial-style hint in the corner (like the "move with W A S D" one) showing which key cycles brightness. It stays until you press the key, comes back on the next world join if you never did, and never shows again once you have.
- The mod now has an icon, links to its source and issue tracker, and includes its license file.
- Fewer downloads: one file now covers every Minecraft version it has been tested on (see the version list on each file).
- Minecraft 1.14.3 is no longer supported: no Fabric API release for 1.14.3 includes what the mod needs, so it could not pass testing there. Older files for 1.14.3 stay available. 1.14.4 and newer are unaffected.
